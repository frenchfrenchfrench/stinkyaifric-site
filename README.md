# stinkyaifric.ie

The main website. Plain HTML, CSS and JavaScript, with no build step.

| File | What it does |
|---|---|
| `index.html` | The page: title and the link buttons. Add new links here. |
| `style.css` | Colours, sizes and layout |
| `swirl.js` | The animated background |

**To preview:** double-click `index.html` to open it in your browser.

**To publish a change:** run `git add -A`, then `git commit -m "what changed"`, then `git push`. Cloudflare Pages updates the live site within a minute or two.
